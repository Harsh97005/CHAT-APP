# 💬 Chat App

A modern real-time chat application built using React and Firebase. This app allows users to communicate instantly with a clean and responsive user interface inspired by modern messaging platforms.

## ✨ Features

- 🔐 User Authentication
- 💬 Real-Time Messaging
- 👤 User Profiles
- 🟢 Online/Offline Status
- 📱 Responsive Design
- ⚡ Fast & Smooth Experience
- ☁️ Firebase Integration

## 🛠️ Tech Stack

- React.js
- Firebase
- Vite
- CSS / Tailwind CSS

## 🚀 Getting Started

```bash
npm install
npm run dev
